# 角色资料查询器 — 工程说明书总索引

这里是项目的**全部工程文档**，按「工作区块」拆分。每个区块一份独立文件，独立描述该区块的
**职责边界 / 实现细节 / 关键函数 / 修改指引 / 验证方式 / 本区块改动历史**，便于单点查阅与二次开发。

> **维护约定（重要）**
> 1. 任何功能新增、逻辑修改、问题修复，除了改代码，还必须更新两份文档：
>    - 对应区块文件里的「本区块改动历史」小节（写清改了什么、为什么改）；
>    - `10-变更记录/CHANGELOG.md` 追加一条版本条目（涉及文件 + 验证方式）。
> 2. 根目录 `README.md` 只保留项目简介与文档入口，不再承载详细内容。
> 3. 新增工作区块时，在本文件「区块地图」补一行，并新建对应子目录。

## 四、文档写作规范

- **一个区块一个文件**，文件名以两位序号开头，保证目录内排序稳定。
- 固定小节顺序：`适用范围` → `实现细节` → `关键函数 / 契约` → `修改指引` → `本区块改动历史` → `验证方式`。
- 引用代码时写「文件名 + 函数名 / CSS 选择器」，便于直接检索定位。
- 涉及颜色、键名、通道名等契约值，必须写具体字面值，不写「若干」「相关配置」。
