## 3. 四份偏好，一个读写口

| key | 取值 | 默认 | 谁读 |
| --- | --- | --- | --- |
| `clw:theme` | `light` \| `dark` \| `system` | `system` | `theme-init.js` → `data-theme` |
| `clw:charLayout` | `list` \| `grid` \| `compact` | `list` | `renderer.js` → `loadLayout()` |
| `clw:reduceMotion` | `'1'` \| `'0'` | 关 | `theme-init.js` → `html.reduce-motion` |
| `clw:panelOpacity` | `55`–`100` | `82` | `theme-init.js` → `--panel-opacity` |

**为什么放在 `theme-init.js`**：这几项都影响首屏。放到 `DOMContentLoaded` 会先按默认值渲染
一帧再切（闪色 / 闪动效 / 闪通透度）。`theme-init.js` 在 `<head>` 里同步跑，
CSS 生效前就把属性写好。

`window.Theme` 因此不只是主题门面，还是这几份偏好的**唯一解析器**：

```js
Theme.get() / Theme.resolve(pref) / Theme.set(pref) / Theme.current()
Theme.getReduceMotion() / Theme.setReduceMotion(on)
Theme.getPanelOpacity() / Theme.setPanelOpacity(v)
```

`renderer.js` 里的 `loadReduceMotion()` / `loadPanelOpacity()` 只是薄封装：
有 `Theme` 就转调，没有才自己读 localStorage（防御 `theme-init.js` 缺失）。

## 4. 四个分区

### 4.1 主题外观 —— 滑动背板

```html
<div class="seg nav-pill-host" id="segTheme">
  <span class="nav-pill" aria-hidden="true"></span>
  <button class="seg-item" data-value="light">浅色</button>
  <button class="seg-item" data-value="dark">深色</button>
  <button class="seg-item" data-value="system">跟随系统</button>
</div>
```

- 选中态**不画在条目上**（`.seg-item.active` 只有文字变色），底衬由 `.nav-pill` 画；
  条目自己再画一层会盖住背板滑过去的瞬间。
- 点击 → `setTheme(value)` → `Theme.set()` → `syncSettingsUI()` → `placePill('#segTheme')`。
- 面板刚打开时必须是 **instant 落位**：`#settingsModal` 之前是 `display:none`，
  所有 `offsetWidth` 都是 0；`openSettings()` 里先 `openDialog()` 再
  `placePill('#segTheme', true)`，顺序不能换。

### 4.2 角色列表布局 —— 选中卡片

三张卡（`list` / `grid` / `compact`），每张卡内有一个 46×33 的 `lc-preview` 线框图。
选中态：`border-color: var(--accent)` + `background: var(--accent-soft)` + 右侧勾号
（`.lc-check` 用 `opacity + scale` 过渡，不用 `display`）。

- 悬停 `translateY(-2px)`（大卡片档），按下 `scale(.995)`（几乎不动，避免"跳一下"）。
- 切换即落盘：`setLayout()` → `saveLayout()` → `renderList()`。

### 4.3 动效 —— 两档开关

```html
<label class="set-row">
  <span class="set-row-text"><b>减少动效</b><em>…</em></span>
  <span class="toggle"><input type="checkbox" id="optReduceMotion"></span>
</label>
```

- 原生 `checkbox` + `appearance: none` + `::after` 自绘圆钮：
  44×26，圆钮 20，行程 18（`44 - 3*2 - 20`）。
- 只过渡 `background-color` 与圆钮 `transform`，**不碰 `left`**。
- `change` → `applyReduceMotion()` → 挂/摘 `html.reduce-motion` + 落盘 + `Motion.cancelAll()`。

### 4.4 面板通透度 —— 滑杆

- 只写一个变量：`--panel-opacity`（55–100 → 0.55–1.00）。
- 拖动时 `input` 事件走 `{ persist: false }`（实时改样式但不落盘），
  松手 `change` 才写 localStorage —— 避免每移动一像素写一次。
- 两个主题的 `--panel-bg` 都引用它，所以调一次两边都生效。

## 5. 弹窗开合：`Motion.dialog`

设置面板和其它四个弹窗共用一套开合逻辑（详见 `11-01 §5`）。要点：

- 打开：`opacity 0→1`（220ms `--e-mech`）+ 卡片 `translateY(10px) scale(.985) → 0/1`。
- 关闭：170ms `ease-in`，卡片刻意只收到 `translateY(6px) scale(.985)`（比打开浅）。
- 关闭期间 `el.inert = true`，键盘不会钻进正在消失的弹窗。
- 用 `motion` 对象标识判断是否被新动画接管：中途再点一次会从当前帧反向，不跳帧。

`Esc` 与点遮罩都走 `closeSettings()`。与角色表单不同，设置面板**允许**点遮罩关闭
（里面只有"选中即生效"的项，没有未保存内容）。

## 6. 自检片段

```js
const cs = (el, p) => getComputedStyle(el)[p];

// 主题三选：背板而不是条目底
document.querySelector('#segTheme .seg-item[data-value="light"]').click();
cs(document.querySelector('#segTheme .nav-pill'), 'width');        // '178px'
cs(document.querySelector('.seg-item.active'), 'backgroundColor');  // 'rgba(0, 0, 0, 0)'（透明，底衬在背板上）

// 布局
document.querySelector('#segLayout .layout-card[data-value="compact"]').click();
document.querySelector('#charList').classList.contains('compact');   // true
document.querySelectorAll('.layout-card.active').length;             // 1

// 减少动效（双闸门的第一道）
const rm = document.querySelector('#optReduceMotion');
rm.checked = true; rm.dispatchEvent(new Event('change', { bubbles: true }));
document.documentElement.classList.contains('reduce-motion');        // true
cs(document.querySelector('#btnNew'), 'transitionDuration');         // '1e-05s'（.01ms）
localStorage.getItem('clw:reduceMotion');                            // '1'

// 通透度
const r = document.querySelector('#optPanelOpacity');
r.value = '60'; r.dispatchEvent(new Event('input', { bubbles: true }));
cs(document.querySelector('.app-shell'), 'backgroundColor');         // 'rgba(..., 0.6)'
document.querySelector('#panelOpacityHint').textContent;             // '60%'

// 恢复默认
document.querySelector('#settingsReset').click();
// clw:theme=system  clw:charLayout=list  clw:panelOpacity=82  clw:reduceMotion=0
```

> Windows 150% 缩放下 `1px` 边框的 computed 值显示为 `0.666667px`（按设备像素吸附），
> 属正常现象，不是样式写错。
