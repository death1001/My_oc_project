# 08-03 · 设计语言与交互规范（DSH-X）

> 引入版本：v2.0（2026-10-29）。本文是**改样式前必读**的一篇：
> 令牌表、曲线表、交互模式、反模式都在这里，组件实现细节见 `08-02` 与 `11-01`。

---

## 1. 这套 UI 的三条纪律

界面好看**不来自配色或插画**，来自三件事：

1. **动效有统一语汇** —— 6 条缓动曲线 + 6 个时长档位，任何动画只从表里挑，禁止 `ease-in-out` 现编。
2. **切换有空间方向感** —— 选中态用「滑动背板」（一块浮起的卡片从旧位置滑到新位置），
   面板切换「快出慢进」（退 90ms / 进 260ms），用户建立的是空间地图，不是"页面刷新了"。
3. **操作有确定反馈** —— 悬停抬 1px、按下缩到 0.96、禁用只降透明度（不改颜色、不改形状）。

### 2.1 三个必须记住的坑

**① 暗色下 `--accent` 是灰白，不是蓝。**
所以 `.btn-primary` 在暗色里是「白底深字」。任何地方都不要写 `color: #fff`，
一律用 `var(--on-accent)`。写死一次，暗色下就是白字白底。

**② 压在照片上的文字固定用白色/白底深字，不进令牌体系。**
`.char-card-info`（底部渐变条 + 白字）与 `.char-card-tag`（白底深字）属于
"照片上的叠加层"，两种主题下都成立，故意不跟主题变量走。

**③ 危险色在暗色里**有意**保留玫瑰色相**（`#ff8fa8`），这是对规范的一处偏离：
删除是不可逆操作，让它和普通按钮长得一样是可用性倒退。已在 `CHANGELOG` 记录。

## 3. 控件几何：四个变量管全套

```css
:root {
  --control-height: 36px;      /* 所有横向控件同高 */
  --control-font-size: 13px;
  --control-radius: 9px;
  --control-padding: 12px;
  --control-height-sm: 30px;   /* 小号按钮 / 动态行输入 */
}
```

`.btn` / `.search` / `.filter` / `.form-grid input` / `.dyn-input` / `.editor-title`
全部 `height: var(--control-height)` + `padding: 0 var(--control-padding)` + `border-radius: var(--control-radius)`。

> 先有变量再写组件，是"到处都齐"的根本原因。历史教训：工具栏里混着 28 / 30 / 32 / 36 四种高度，
> 上下沿永远差 1~2px，怎么调单个控件都对不齐。

### 圆角与阴影层级

| 用途 | 圆角 | 阴影 |
| --- | --- | --- |
| 药丸按钮 / 标签 / 开关 | `999px` | 无 |
| 控件（输入框、下拉、按钮） | `9px` | 无 / 悬停 `0 3px 10px` 主色染色 |
| 卡片 | `16px` | `0 12px 32px rgb(59 111 224 / .10)` |
| 外壳 | `22px` | `0 18px 52px rgb(43 77 137 / .16), 0 3px 10px …` |
| 弹窗 | `18px` | `0 18px 44px rgb(22 35 61 / .18)` |

规律：**层级越高，模糊越大、透明度越低；卡片阴影染主色，浮层阴影中性。**

### 排版

| 层级 | 规格 |
| --- | --- |
| 主视觉姓名 `.char-name` | 26px / 700 |
| 故事标题 `.story-detail-title` | 23px / 700 |
| 弹窗标题 | 17px / 650 |
| 列表主名 | 13.5px / 600 |
| 说明文字 | 12.5px / 400，`--muted`，line-height 1.7 |
| 微标签（分组小标题 `.panel-card h3` / `.qi-tag`） | 12px + `letter-spacing: .08em` + `--muted` |
| 数字（端口、版本、计数） | `font-variant-numeric: tabular-nums` |
| 等宽（路径、版本号） | `ui-monospace, Consolas, monospace` |

字重用 **650**（不是 700）——在 Segoe UI 上比 600 实、比 700 轻，是"精致感"的隐藏细节。

## 4. 动效语汇（核心）

曲线只这 6 条，各有语义：

| 令牌 | 值 | 语义 | 典型用法 |
| --- | --- | --- | --- |
| `--e-bounce` | `cubic-bezier(.2, 1.3, .32, 1)` | 弹到位（末端轻微过冲） | 背板滑动、面板入场 |
| `--e-land` | `cubic-bezier(.22, 1, .36, 1)` | 落位（无过冲，最通用） | 列表补位、内容入场 |
| `--e-mech` | `cubic-bezier(.2, .8, .2, 1)` | 机关动作（干脆） | 开关圆钮、卡片悬停 |
| `--e-fold` | `cubic-bezier(.22, .61, .36, 1)` | 高度 / 折叠 | `<details>` 展开 |
| `--e-large` | `cubic-bezier(.16, 1, .3, 1)` | 大元素入场 | 封面图缓推 |
| `--e-exit` | `cubic-bezier(.4, 0, 1, 1)` | 退出加速 | 面板退场 |

时长档位（不要发明新数字）：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--t-micro` | 140ms | 悬停变色、行背景 |
| `--t-tap` | 140ms | 按下 `scale(.96)` |
| `--t-std` | 200ms | 开关滑块、按钮位移、弹窗 |
| `--t-switch` | 260ms | 背板滑动、面板入场 |
| `--t-layout` | 380ms | 侧栏宽度、封面图放大 |
| `--t-exit` | **90ms** | 面板退场（唯一一个"短到不像话"的档位） |
| `--t-enter` | 260ms | 面板入场 |

**最关键的"快出慢进"**：退场 90ms 加速离开（别让用户等），入场 260ms 带回弹落定。
退场和入场用同一时长会让切换显得"两边一样沉"，像卡了一下。

`motion.js` 读取的是别名（`--mo-dur-exit` / `--mo-dur-enter` / `--mo-shift-x` = 48px /
`--mo-ease-out` = `--e-bounce` / `--mo-ease-in` = `--e-exit`），
所以**改时长只改 CSS 一处**，JS 不存魔法数字。

## 5. 五个交互模式（本项目已落地）

| 模式 | 落点 | 实现 |
| --- | --- | --- |
| **A 滑动背板** | 侧栏角色/故事、详情四标签、主题三选 | `motion.js` 的 `pill(host).place()` + `.nav-pill`；宿主挂 `ResizeObserver`，尺寸一变就重量（背板尺寸是一次性量的 px，不重量会漂） |
| **B 快出慢进面板** | `#detail` ⇄ `#globalStoryDetail`、`#charsView` ⇄ `#storiesView` | `motion.js` 的 `swap()` |
| **C 按钮三层反馈** | 全站 `.btn` | 纯 CSS（hover 抬 1px / active .96 / disabled 只降透明度） |
| **D 开关乐观更新** | 设置「减少动效」 | `.toggle` 自绘圆钮 + `transition 220ms`，UI 先改不等结果 |
| **G 折叠高度动画** | 角色表单 7 个分区 | `renderer.js` 的 summary 点击拦截 + WAAPI |
| **H 弹窗开合** | 5 个弹窗 | `motion.js` 的 `dialog(el, opening)` |
| **I 减少动效双闸门** | 全站 | `html.reduce-motion` + `prefers-reduced-motion` |

未落地：模式 E（FLIP 列表）与模式 F（悬停浮层）。原因：

- 列表已经有**指纹机制**（`charListFingerprint()`）：只换选中项时完全不重建 DOM，
  只有筛选/排序变化才重建，此时用 stagger 淡入即可。做 keyed FLIP 需要改造成
  "复用节点 + 手工 diff"，收益（筛选时不重载图片）小于回归风险。
- 本工程没有悬停菜单/浮层，`Popover` 模式无处安放。

## 6. 反模式清单（踩过或差点踩的）

| 坑 | 症状 | 正确做法 |
| --- | --- | --- |
| 选中态"两层都画" | 背板滑过去时被条目自己的高亮盖住 | 有背板时把条目选中态清空（`.side-tab.active { background: transparent }`） |
| 用百分比做切换位移 | 长内容上飞出屏幕 | 固定 48px |
| 动画结束不 `cancel()` | 元素卡在 `opacity: 0` / 焦点跑偏 | `fill:'both'` + 结束 `cancel()` |
| `transition: all` | 宽度变化时意外触发位移，抖动 | 逐属性列举 |
| 祖先 `opacity` 动画 + `backdrop-filter` | 毛玻璃在动画中变透明 | 只动内容层；本版干脆不给遮罩加模糊 |
| 在大面积元素上叠 `backdrop-filter` | 背景光斑一动，每帧重算全窗模糊 | 光斑自己已 `blur(70px)`，外壳不再采样 |
| 异步操作期间把控件灰掉 | 看起来像坏了 | 保持 `opacity: 1`，只 `disabled` |
| `100vh` + flex 内部滚动 | 弹窗被顶出屏幕且滚不动 | `100dvh` + 子元素 `min-height: 0` |
| 只有一个闸门 | 设置关了但还在动 | `reduced() = 系统偏好 \|\| html.reduce-motion` |
| 固定画框里用 `object-fit: contain` 放照片 | 横图上下（或竖图左右）留白，露出占位底色，看着像没加载完 | 定长画框里的照片一律 `cover`；只有"预览用户刚选的原始文件"（`.image-preview`）才用 `contain` |
| `cover` 却不写 `object-position` | 竖图从中间裁，头被切一半 | `50% 25%`：横图纵向参数不生效（等于居中），竖图偏上取景保住头部 |
| 用 `.01ms` 之外的值做降级 | `transitionend` 不触发，逻辑卡死 | 用 `.01ms`（保留事件）而不是 `none` |
| 装饰动画一直 rAF | 挂机吃一个 CPU 核 | 光斑 38–52s 一次、纯 transform、减少动效时静止 |

## 7. 视觉氛围

1. **背景是三团高斯光斑**（`.bg-bloom > i`）：`blur(70px)` + 三个不同相位/周期的
   `translate3d` 漂移（38s / 44s / 52s），只动 transform，走合成器。
2. **外壳是一块浮起的圆角面板**：窗口内留 12px 呼吸位，`border-radius: 22px`，
   底色 `rgb(255 255 255 / var(--panel-opacity))` —— 通透度由设置里的滑杆写这个变量，
   光斑从底下透出来，就是"毛玻璃"的观感，但**零 `backdrop-filter`**。
3. **为什么不真做 `backdrop-filter`**：光斑本身已是高斯模糊的大色块，
   再采样一次在视觉上几乎没有区别，代价是每帧全窗口模糊。这条取舍写在 `CHANGELOG`。

## 8. 修改指引

| 想做的事 | 改哪里 |
| --- | --- |
| 换主色 | `styles.css` 两处 `--accent` / `--accent-hover` / `--accent-soft` / `--accent-dim`，**别碰 `--on-accent`** |
| 整体调大/调小控件 | 只改 `--control-height` / `--control-padding` / `--control-font-size` |
| 让动效更快/更慢 | 只改 `--t-*` 六个档位；`motion.js` 会自动跟上 |
| 加第三套主题 | 复制一个 `html[data-theme="paper"] { … }` 变量块，`theme-init.js` 的 `resolve()` 白名单加值 |
| 加新图标 | `index.html` 顶部 `<svg class="icon-sprite">` 加 `<symbol id="i-x">`，用 `icon('x')` 或 `<svg class="ico"><use href="#i-x"/></svg>` |
| 加新弹窗 | 复用 `.modal-mask > .modal[data-dialog-size]`，开合用 `openDialog()` / `closeDialog()` |

**新增颜色的铁律**：先在两个主题变量块里定义，再在组件里 `var()` 引用。
直接写 hex，暗色主题下必然是坏的（白底白字或深底黑字）。
