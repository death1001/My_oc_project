# 侧栏切换与页面转场动效

> 适用版本：v2.0 ｜ 主要负责人：`motion.js`、`styles.css`（§3 动效语汇）、`renderer.js`、`index.html`
> 曲线与时长令牌的**语义解释**在 `08-03 设计语言与交互规范 §4`，本篇讲代码怎么用。

---

## 1. 前置事实：本工程没有路由

| 概念 | 本工程真实实现 |
| --- | --- |
| 侧栏 | `<aside class="sidebar">` |
| 侧栏一级项 | `.side-tab`（`data-view="chars" / "stories"`），外面套 `.side-tabs` 凹槽 |
| 二级列表项 | `.char-item` / `.char-card` / `.story-item`（`renderer.js` 生成） |
| 页面 | `#detail`（角色档案页）、`#globalStoryDetail`（故事全文页），互斥的两个 `<section>` |
| 路由 | **无**。靠 `.hidden { display:none !important }` 切换 |
| 详情内分区 | `.tab-btn` + `.tab-panel`（同一页内，不参与页面转场） |

于是"转场"= 同一文档内两个面板的互斥显隐，这带来两个硬约束：

1. `.hidden` 是 `display:none !important`，**退出动画必须在加 `.hidden` 之前播完**；
2. `display:none` 的子树重新显示后**滚动位置会丢**，要手动存取。

---

## 2. 三层结构

```
styles.css   动效令牌（曲线 / 时长 / 位移 48px）+ 背板与面板的基础 transition
   ↑ 读 CSS 变量
motion.js    swap / enter / flip / pill / dialog：统一取消、will-change 管理、双闸门降级
   ↑ 调用
renderer.js  只在「状态切换的那一刻」调一次，不持有任何动画进度
```

设计取舍：

- **只用 transform / opacity**。唯一例外是侧栏宽度（`--t-layout`）与折叠区高度（WAAPI 显式值）。
- **动画状态不入业务 model**。`state` 里只有 `view` / `pane` / `layout` 这类业务事实。
- **串行而非并行**：两个面板是 `display:flex` 的兄弟节点，同时显示会各占一半高度，必须"先出后进"。
- **取消优先于排队**：每次切换都是接管，旧动画立刻 `cancel()`，只有最后一次有权提交 DOM。

## 3. `swap(key, { out, in, direction })` —— 面板切换

```js
Motion.swap('detail-pane', {
  out: $('#detail'),
  in:  $('#globalStoryDetail'),
  direction: 1            // +1 前进（向右），-1 返回
});
```

内部时序：

```
① snapshot(out) / snapshot(in)     取「此刻」视觉值（被打断时从当前帧接续）
② kill(key)                        取消同组旧动画
③ out: opacity→0 + translateX(-dir*28.8)   90ms  --e-exit
④ commit()                         加/删 .hidden + 还原滚动位置
⑤ in:  opacity 0→1 + translateX(dir*48→0)  260ms --e-bounce
```

关键数字：

| 项 | 值 | 理由 |
| --- | --- | --- |
| 位移 | 固定 **48px** | 用百分比在长内容上会飞出屏幕 |
| 退出位移 | `-dir * 48 * 0.6` = 28.8px | 退出比进入"收"一点，视觉上不会两边对撞 |
| 退场 | 90ms `--e-exit` | 别让用户等 |
| 入场 | 260ms `--e-bounce` | 带回弹落位，新内容"落"进来 |
| 方向来源 | `DETAIL_PANE_ORDER = { detail: 0, story: 1 }` | 目标序号 > 源序号 = 前进 = +1 |

同组新切换会 `groups.set(key, group)` 换掉旧 group；旧链的 `await` 回来时
`groups.get(key) !== group` 就直接 `return`，避免"晚到的回调把新页面关了"。

两处调用点：

| key | out / in | 方向 |
| --- | --- | --- |
| `sidebar-list` | `#charsView` ⇄ `#storiesView` | 故事向右、角色向左 |
| `detail-pane` | `#detail` ⇄ `#globalStoryDetail` | 按 `DETAIL_PANE_ORDER` |

## 4. `pill(host)` —— 滑动背板

选中态不是"每项自己亮一下"，而是一块浮起的卡片从旧位置滑到新位置。

```html
<div class="side-tabs nav-pill-host" id="sideTabs">
  <span class="nav-pill" aria-hidden="true"></span>
  <button class="side-tab active" data-view="chars">角色</button>
  <button class="side-tab" data-view="stories">故事</button>
</div>
```

```js
Motion.pill($('#sideTabs')).place();                    // 带动画
Motion.pill($('#segTheme')).place({ instant: true });   // 首次落位，不许滑
```

三条硬要求：

1. **宿主 `position: relative`**，且 `.nav-pill` 是它的**直接子元素**（`left:0; top:0`）；
2. **条目 `z-index: 1`**，背板 `z-index: 0`；
3. **条目选中时不许自己画底**（`.side-tab.active { background: transparent }`），
   否则背板滑过去的瞬间会被条目高亮盖住。

JS 只写三个值，不做插值：

```js
el.style.width  = active.offsetWidth  + 'px';
el.style.height = active.offsetHeight + 'px';
el.style.transform = 'translate3d(' + active.offsetLeft + 'px,' + active.offsetTop + 'px,0)';
```

滑动本身交给 CSS：`transition: transform/width/height 260ms --e-bounce, opacity 140ms`。

**首次落位**（`instant`）会临时挂 `.instant { transition: none }`，强制回流一帧后再通过
`requestAnimationFrame` 摘掉 —— 否则面板刚打开时背板会从左上角"飞"过来。

三处宿主：

| 宿主 | 条目 | 背板圆角 | 备注 |
| --- | --- | --- | --- |
| `#sideTabs` | `.side-tab` | 8px | 侧栏角色/故事 |
| `#detailTabs` | `.tab-btn` | 10px | 详情四分区 |
| `#segTheme` | `.seg-item` | 10px | 设置主题三选 |

**隐藏容器陷阱**：`#settingsModal` / `#detailContent` 初始是 `display:none`，
里面所有 `offsetWidth` 为 0。必须在**变为可见之后**才 place，且用 `instant`。
`renderer.js` 的落点是：`openSettings()` 里 `openDialog()` 之后立刻
`placePill('#segTheme', true)`；`renderDetail()` 里 `#detailContent` 取消 hidden 之后
`placePill('#detailTabs')`（第一次自动走 instant 分支）。`place()` 内部还有一道
`if (!host.offsetWidth) return;` 的兜底，宿主不可见时直接放弃，不会把背板压成 0×0。

**尺寸漂移陷阱（v2.0.1 修复）**：背板尺寸是**一次性量出来的 px**，宿主一变宽就失效。
两处会变：侧栏随布局在 300⇄352 间过渡（`--t-layout` 380ms）、`#detailTabs` 随窗口宽度变化。
症状是"选中块明显偏移、盖不满标签"——例如切到网格布局后标签 141.7px、背板还停在 116px，差 25.7px。

修法：`pill()` 里给宿主挂 `ResizeObserver`，尺寸真的变了就 `place({ instant: true, hold: true })`：

- `instant` —— 让背板逐帧贴住宿主，而不是用 260ms 过渡去"追"；
- `hold` —— 连续变化期间保持 `transition: none`，停下 220ms 后再把过渡还回来；
- `if (host.offsetWidth === placed._lastW) return;` —— 尺寸没变就跳过，避免把刚播的切换动画搅乱
  （ResizeObserver 注册时会先回调一次，没有这道判断就会把首次落位重放一遍）。

另外 `applyLayout()` 在切完 `.grid-mode` 后也显式 `placePill('#sideTabs', true)` 兜底。
窗口 resize 的 80ms 防抖重算保留（`ResizeObserver` 缺失时的退路）。

## 5. `dialog(el, opening)` —— 弹窗开合

```js
Motion.dialog($('#settingsModal'), true);    // 开
Motion.dialog($('#settingsModal'), false);   // 关（返回 Promise<boolean>）
```

三个必须照抄的细节：

1. **从当前实际样子起步**：`reverse = !!prev` 时读 `getComputedStyle` 的
   `opacity` / `card.transform` 作为起点，中途反向不会跳回固定帧。
2. **关闭中 `el.inert = true`**：键盘不会钻进正在消失的弹窗；结束再置回 `false`。
3. **`motion` 标识比对**：`dialogMotions.get(el) !== motion` 时直接返回 `false`，
   晚到的回调不许关掉被重新打开的弹窗。

时长 / 曲线：

| 方向 | 时长 | 曲线 | 卡片位移 |
| --- | --- | --- | --- |
| 开 | 220ms | `--e-mech` | `translateY(10px) scale(.985)` → `0 / 1` |
| 关 | 170ms | `ease-in` | `0 / 1` → `translateY(6px) scale(.985)` |

遮罩**不做** `backdrop-filter`：它要做 opacity 动画，而祖先的 opacity 动画会隔断
`backdrop-filter` 的采样，模糊会在动画期间消失。遮罩只用 `--mask` 半透明底色。

层级：`.modal-mask` z-index 100，`#confirmModal` 120，`#toast` 300。

## 6. 折叠区高度动画（`<details>`）

角色表单的 7 个分区是 `<details class="fold">`。原生 details 关闭时会立刻移走内容，
高度无法过渡；Chromium 130 也还不支持 `::details-content`。所以走 JS 路线：

```
click on summary
  → preventDefault()
  → opening = prev ? !prev.opening : !details.open     ← 中途反向的关键
  → from = 当前高度
  → details.open = opening → 量 to → details.open = true（动画期间必须展开）
  → animate([{height:from},{height:to}], 220ms --e-fold)
  → onfinish: details.open = opening; 清理 inline overflow
```

`prev ? !prev.opening : !details.open` 这一句让"动画中途再点一次"能从当前高度反向，
而不是先跳回原位再重播。

减少动效时**不拦截**（直接 `return`），交给原生开关，避免动画与 DOM 状态打架。

## 7. `flip(key, sourceImg, frameEl)` —— 共享元素

卡片封面 → 详情立绘框。克隆一个 `background-image` 图层从封面矩形飞到立绘框矩形，
飞行期间真实立绘透明，落位后克隆体在最后 15% 淡出交棒。

- 落点是 **`.portrait-frame`（300×380）**，不是 `#portraitImg`：
  立绘多为横图，`object-fit: contain` 后实际显示 300×169，与 3:4 卡片硬套会变形；
  框的宽高比与卡片接近，等比缩放即可无缝衔接，差异由结尾淡出遮掉。
- 放弃条件：无立绘 / 未解码 / 缩放比 < .6 或 > 4.5 / 减少动效 / 元素隐藏。
- 只在卡片布局（`grid` / `compact`）下启用：列表模式的小头像放大 5 倍会糊。

## 8. 双闸门降级

```js
const reduced = () =>
  matchMedia('(prefers-reduced-motion: reduce)').matches ||
  document.documentElement.classList.contains('reduce-motion');
```

| 闸 | 触发 | 实现 |
| --- | --- | --- |
| 1 | 设置里的「减少动效」 | `html.reduce-motion` + CSS 里 `*{transition-duration:.01ms!important}` |
| 2 | 系统「减少动态效果」 | `@media (prefers-reduced-motion: reduce)` |

两处细节：

- 用 `.01ms` 而不是 `none`：保留 `transitionend` / `animationend`，依赖事件回滚的逻辑不会卡死。
- **JS 与 CSS 必须都是"或"关系**，只查一处就会出现"设置关了但还在动"。
  `swap()` / `enter()` / `flip()` / `dialog()` / 折叠拦截的第一行都是 `reduced()`。

另有低端设备降级：`hardwareConcurrency ≤ 4` 或 `deviceMemory ≤ 4` 时挂 `html.mo-lite`，
位移减半（48→24px）、入场 260→190ms，信息结构不变。

## 9. 验收（v2.0 实测，DOM 探测 + `CSS.forcePseudoState`）

| 检查项 | 实测 |
| --- | --- |
| 标签页背板滑动 | `translate3d(4px,4px,0)` → `translate3d(781px,4px,0)`，`transition-duration` 0.26s×3 + 0.14s |
| 背板尺寸对齐 | 宽 257 / 高 34，与 `.tab-btn` 的 `offsetWidth/offsetHeight` 一致 |
| 侧栏背板 | `translate3d(3px,3px,0)`，宽 116 高 28，与 `.side-tab.active` 完全重合 |
| 背板跟随宿主（v2.0.1） | 切网格布局：过渡中 150ms 时标签 138.9 / 背板 139.0；稳定后 141.7 / 142.0；切回列表 115.7 / 116.0。三处宿主全程 `dx ≤ 0.4px`、`dy = 0`，无残余 `.instant` |
| 面板转场 | 退场 90ms 后 `commit()`，入场 260ms；连点由 group 身份比对兜底 |
| 弹窗开合 | 打开后 `opacity:1`、`.modal` 600px / 圆角 18px；关闭后 `.hidden=true`、`inert=false` |
| 折叠区 | 397px →（60ms 时 212px，动画中）→ 78px（仅 summary）；再点回到 397px |
| 减少动效（应用内） | `html.reduce-motion=true`、按钮 `transition-duration: 1e-05s` |
| 减少动效（关闭后） | `transition-duration: 0.14s, 0.14s, 0.14s, 0.2s, 0.14s` |
| 悬停反馈 | 主按钮 `matrix(1,0,0,1,0,-1)` + 主色阴影；卡片 `matrix(1.02,0,0,1.02,0,-2)`；侧栏闲置项文字转 `--text` |
| 控制台 | 0 条 error / warning |

> 探测方式：临时在 `main.js` 挂 `did-finish-load` 钩子 + `webContents.executeJavaScript`
> 读计算样式，`webContents.debugger`（`DOM.enable` / `CSS.enable` /
> `Emulation.setFocusEmulationEnabled` / `CSS.forcePseudoState`）读 `:hover`。
> 钩子与探针脚本用完已删除。

**踩过的坑**：`sendInputEvent('mouseMove')` 在未聚焦窗口里触发不了 `:hover`；
`CSS.forcePseudoState` 单独用也不够，要先 `Emulation.setFocusEmulationEnabled`，
且 force 之后要等 ≥ 400ms（有 transition 的元素要等过渡走完才是终值）。
