# 04-02 · 角色表单与头像裁剪

## 1. 适用范围

| 层 | 位置 |
| --- | --- |

## 2. 一个弹窗装下全部字段

表单分区（自上而下）：形象图片 → 基本信息 → 能力 → 武器 → 战斗属性 → 四类关系 → 元信息。

| 分区 | 输入控件 | 落库字段 |
| --- | --- | --- |
| 形象 | 头像 / 立绘选择、预览、移除 | `avatar_path` / `portrait_path`（由主进程写） |
| 基本 | `#f_name` `#f_alias` `#f_age` `#f_gender` `#f_race` `#f_birth_date` `#f_birth_place` `#f_affiliation` `#f_profession` `#f_personality` | 同名字段 |
| 能力 | `#abilitiesRows` 动态行 | `abilities: [{name, description, level}]` |
| 武器 | `#weaponsRows` 动态行 | `weapons: [{name, type, description}]` |
| 战斗属性 | `#combatStatsRows` 动态行 | `combat_stats: {k: v}` |
| 关系 | `#familyRows` / `#companionsRows` / `#rivalsRows` / `#mentorsRows` | `relationships: {family, companions, rivals, mentors}` |
| 元信息 | `#f_work` `#f_first_appearance` `#f_rarity` `#f_tags` | `metadata: {work, first_appearance, rarity, tags[]}` |

### 2.1 打开时的回填

`openCharForm(character)`：

1. 重置 `formState`（`editingId`、`avatarSrc`、`portraitSrc`、`avatarCropData`、两个 `remove*` 标记）；
2. 逐字段 `value = character.xxx || ''`，`age` 单独处理 `null → ''`；
3. 清空所有动态行容器（`abilitiesRows` / `weaponsRows` / `combatStatsRows` / 四个关系容器）；
4. 按已有数据逐条 `addDynRow()`；
5. `resetImagePreview('avatar'|'portrait', path)` 显示原图缩略；
6. 显示弹窗并聚焦姓名输入框。

新建（`openCharForm(null)`）走同一路径，只是全部为空。

### 2.2 动态行编辑器

```js
addDynRow(containerSel, inputs)   // inputs: [{cls, placeholder, value}]
collectRows(containerSel, fields) // → 对象数组
```

- 每行是一个 `.dyn-row`：N 个 `.dyn-input` + 一个 `.dyn-remove`（✕）；
- `inputs` 的 `cls` 决定宽度（`inp-wide` 宽 / `inp-short` 窄），纯样式控制；
- `collectRows` 按 `fields` 数组顺序映射输入框 → 对象键；
- **空行自动过滤**：只要该行所有值都是 `''` 就不产出对象；
- 值统一 `trim()`。

`collectCombatStats()` 额外做类型转换：

```js
out[key] = (v !== '' && !isNaN(Number(v))) ? Number(v) : v;
```

能转数字就存 Number（`hp: 100`），否则原样存字符串（`速度: 极快`）。
空键名跳过，避免产生 `"": 值` 这种脏数据。

### 2.3 保存

`saveCharForm()`：

1. **必填校验**：姓名 `trim()` 为空 → `toast('请填写姓名','warn')` + 聚焦，不提交；
2. 组装 `data`（字段 + 三个动态集合 + 关系 + 元信息；`tags` 按 `/[,，]/` 拆数组）；
3. `formState.editingId` 有值 → `updateCharacter({id, ...data, 图片相关})`；否则 `createCharacter({...data, 图片相关})`；
4. 保存期间 `btn.disabled = true`，`finally` 恢复，防连点重复提交；
5. 成功 → 关弹窗 → toast → `loadCharacters(newId)` 刷新列表并选中该角色。

**表单不绑定「点遮罩关闭」**（与其他弹窗不同）：避免误触遮罩丢失未保存的编辑内容。
只能通过 ✕ / 取消 / 保存退出。

## 3. 图片选择与预览

```js
pickImageFor(slot)
 ├── bridge.pickImage()         系统文件框
 ├── 取消 → 直接 return（不提示）
 ├── slot === 'avatar' → openAvatarCrop(srcPath)   ← 头像进裁剪
 └── slot === 'portrait' → formState.portraitSrc = srcPath，直接预览原图
```

- 立绘不裁剪，保持原图（很多立绘是竖长构图，裁了反而破坏）。
- `removeImageFor(slot)`：清掉对应 `formState` 值并置 `remove* = true`，预览区显示「已移除」。
- 预览用 `toFileUrl(srcPath)` 直接把本地绝对路径转成 `file://`（渲染进程不能 `fs`，但 `<img src>` 可以加载）。

## 4. 头像圆形裁剪

### 4.1 画布参数

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `CROP_SIZE` | 440 | 画布边长（正方形） |
| `CROP_RADIUS` | 150 | 圆形选区半径 |
| 初始缩放 | `min((440-20)/w, (440-20)/h)` 与 `cropMinZoom()` 取大 | 图片恰好铺满画布 |
| 缩放上限 | 12× | 防止放大到像素糊成一片 |
| 每次滚轮步进 | ×1.15 / ÷1.15 | 手感连续 |
| 输出边长 | `clamp(圆形在源图中的像素直径, 128, 512)` | 太小糊、太大占空间 |

### 4.2 状态

```js
cropState = { img, zoom, offX, offY, dragging, dragStartX, dragStartY, dragOffX, dragOffY }
```

`offX/offY` 是**图片左上角在画布坐标中的位置**，不是图片中心——所有换算都基于这个原点。

### 4.3 三个几何约束

**① 最小缩放 `cropMinZoom()`**

```js
Math.max((CROP_RADIUS*2)/img.naturalWidth, (CROP_RADIUS*2)/img.naturalHeight)
```

保证图片任一边缩放后都不小于圆形直径——否则圆内会露出透明区域。

**② 位置约束 `clampCrop()`**

```js
minX = cx + R - imgW;   maxX = cx - R;
minY = cy + R - imgH;   maxY = cy - R;
offX = clamp(offX, minX, maxX);
```

含义：图片左边缘必须 ≤ 圆的左切点，右边缘必须 ≥ 圆的右切点，即圆永远被图片完全覆盖。

**③ 以鼠标为锚点缩放 `onCropWheel()`**

```js
px = (mx - offX) / zoom;        // 鼠标位置对应的源图像素
py = (my - offY) / zoom;
zoom = clamp(zoom * factor, cropMinZoom(), 12);
offX = mx - px * zoom;          // 保持该像素仍在鼠标下
offY = my - py * zoom;
clampCrop(); drawCrop();
```

常见错误是「以画布中心缩放」，手感会很别扭（想放大眼睛结果脸跑出圆外）。锚定鼠标位置后放大时目标始终跟着指针。

### 4.4 绘制

```js
ctx.beginPath();
ctx.arc(CROP_SIZE/2, CROP_SIZE/2, CROP_RADIUS, 0, Math.PI*2);
ctx.clip();                                   // 只画圆内
ctx.drawImage(img, offX, offY, imgW, imgH);
```

圆形之外不绘制 → 画布透明。弹窗上再叠一层 CSS 半透明遮罩圈出圆形区域，形成「圆外变暗」的取景效果。

### 4.5 输出

```js
cropPx = (CROP_RADIUS*2) / zoom;             // 圆在源图里覆盖多少像素
icx = (cx - offX) / zoom;                    // 圆心对应的源图坐标
outSide = clamp(round(cropPx), 128, 512);

out.width = out.height = outSide;
octx.arc(outSide/2, outSide/2, outSide/2, 0, PI*2); octx.clip();
octx.drawImage(img, icx - cropPx/2, icy - cropPx/2, cropPx, cropPx, 0, 0, outSide, outSide);
dataUrl = out.toDataURL('image/png');
```

- 输出是**正方形 PNG**，四角透明（圆裁剪后），交给界面用 `border-radius: 50%` 显示；
- 只有确认时才真正写文件：`formState.avatarCropData = dataUrl`，保存角色时经
  `characters:create/update` → `saveImageFromDataUrl()` 落盘为 `images/char_{id}/avatar.png`。

### 4.6 交互事件

| 事件 | 处理 |
| --- | --- |
| `mousedown` | 记录起点与当前偏移，`dragging = true`，加 `.dragging` 光标 |
| `mousemove` | `offX = dragOffX + (clientX - startX)`，`clampCrop()` + `drawCrop()` |
| `mouseup` / 离开 | `dragging = false` |
| `wheel` | 锚点缩放（见上），`preventDefault()` 阻止页面滚动 |
| 重置 | `resetCrop()` 回到居中适配状态 |
| 取消 | `closeCropModal()`，不改变 `formState` |

`openAvatarCrop()` 用 `await img.decode()` 等解码完成再打开弹窗，
`decode()` 失败或尺寸为 0 时 toast「无法读取该图片」并放弃——防止 `naturalWidth = 0` 导致后续除零。

## 5. 修改指引

| 需求 | 位置 |
| --- | --- |
| 新增表单字段 | ① `index.html` 加输入框 + `id`；② `openCharForm` 回填；③ `saveCharForm` 组装；④ `database.js` 的 `CHAR_FIELDS` 与 `CREATE_SQL`；⑤ `renderBasicTab` 展示 |
| 改动态行字段 | `openCharForm` 里的 `addDynRow([...])` 与 `saveCharForm` 里的 `collectRows(sel, fields)`，两处数组必须对应 |
| 改裁剪输出尺寸 | `confirmAvatarCrop()` 的 `Math.min(Math.max(...,128),512)` |
| 改裁剪画布大小 | `CROP_SIZE` / `CROP_RADIUS`（**两者要一起改**，且需同步 CSS 里画布的宽高） |
| 让立绘也裁剪 | `pickImageFor()` 里对 `portrait` 也调 `openAvatarCrop`，但需新增一个方形/自由比例裁剪模式，不能直接复用圆形 |
| 允许遮罩关闭表单 | `bindEvents()` 里给 `#charModal` 加 mask 点击监听（**不建议**，易丢数据） |

## 7. 验证方式

**表单**

```js
// 打开新建表单，填最小数据后保存
document.querySelector('#btnNew').click();
document.querySelector('#f_name').value = '__表单测试__';
document.querySelector('#charModalSave').click();
// 列表应出现该角色并选中；再次编辑时应回填全部字段
```

**动态行**

- 添加 3 行能力，其中 1 行全空 → 保存后 `abilities.length` 应为 2。
- 战斗属性填 `hp` / `100` → 详情页显示 `100`，`typeof` 为 number（可通过导出 JSON 核对）。

**裁剪**

| 检查项 | 预期 |
| --- | --- |
| 打开裁剪弹窗 | 图片居中、铺满圆形选区，缩放标签 100% 左右 |
| 缩小到极限 | 停在 `cropMinZoom()`，圆内不出现透明 |
| 拖到边缘 | 图片边缘贴住圆的切点后停住，不会露出背景 |
| 滚轮放大 | 鼠标下的图像内容保持不动（锚点缩放） |
| 确认 | 预览区变成圆形头像（四角透明），保存后 `images/char_{id}/avatar.png` 存在 |
