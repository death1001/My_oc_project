# 03-01 · 三种布局与卡片交互

## 1. 适用范围

| 层 | 位置 |
| --- | --- |
| 结构 | `index.html` → `#charsView` 内的 `#charList` / `#charListEmpty` |
| 逻辑 | `renderer.js` → `LAYOUT_KEY` / `LAYOUTS` / `loadLayout()` / `saveLayout()` / `applyLayout()` / `charItemHtml()` / `charCardHtml()` / `renderList()` |
| 样式 | `styles.css` → `.sidebar.grid-mode` / `.char-list.grid` / `.char-list.compact` / `.char-card*` |
| 入口 | 设置面板「角色列表布局」三张选择卡（见 [08-02](../08-主题与设置/02-设置面板与配色令牌.md)） |

---

## 2. 三种布局对照

| 模式 | 值 | 列数 | 单元 | 侧栏宽 | 显示内容 | 适用 |
| --- | --- | --- | --- | --- | --- | --- |
| 列表 | `list` | 1 | 42px 圆头像 + 两行文字 | 280px | 头像、姓名、别名 | 默认，信息密度最高 |
| 网格 | `grid` | 2 | 3:4 竖卡（约 151×201） | 336px | 立绘封面、姓名、别名、阵营角标 | 认图为主，视觉最好 |
| 紧凑 | `compact` | 3 | 3:4 竖卡（约 100×133） | 336px | 立绘封面、姓名（居中） | 角色多时快速扫视 |

侧栏宽度切换带过渡：`.sidebar { transition: width .2s ease, min-width .2s ease; }`。

## 3. 渲染流程

```
renderList()
 ├── filteredCharacters()        取筛选后的列表
 ├── 更新 #charCount 与空状态
 ├── applyLayout()               按 state.layout 切换容器 class 与侧栏宽度
 ├── 逐条 map → isCards ? charCardHtml(c) : charItemHtml(c)
 ├── 绑定 click（所有模式）+ keydown（卡片模式）
 └── 异步并发取图 → img.onload 后隐藏占位
```

### 3.1 `applyLayout()`

```js
const isCards = state.layout !== 'list' && state.view === 'chars';
box.classList.toggle('grid',    isCards && state.layout === 'grid');
box.classList.toggle('compact', isCards && state.layout === 'compact');
$('.sidebar').classList.toggle('grid-mode', isCards);
$$('.layout-card').forEach(b => b.classList.toggle('active', b.dataset.value === state.layout));
```

三个关键点：

1. **容器 class 与状态解耦**：DOM 只认 `grid` / `compact` 两个 class，二者互斥；
2. **`state.view === 'chars'` 才生效**：故事库视图固定列表，切过去时自动回到 280px 宽；
3. **顺带同步设置面板选中态**：不需要单独再调一次同步函数。

### 3.2 两套模板

- `charItemHtml(c)`：`.char-item` + `.char-avatar`（首字占位 + 隐藏的 `.avatar-img`）+ `.char-item-info`。
- `charCardHtml(c)`：`.char-card`（`tabindex="0" role="button" aria-label`）内含
  `.char-card-cover`（占位 `.char-card-fallback` + `.char-card-img`）、可选 `.char-card-tag`、`.char-card-info`。
- 两者都用 `escapeHtml` / `escapeAttr` 转义，**模板字符串里不出现未转义的用户数据**。
- 选中态：`c.id === state.currentId` 时加 `active` class。

### 3.3 取图优先级

```js
const relPath = isCards ? (c.portrait_path || c.avatar_path) : c.avatar_path;
```

| 模式 | 顺序 |
| --- | --- |
| 列表 | 头像 → 首字占位 |
| 网格 / 紧凑 | 立绘 → 头像 → 首字占位 + 「暂无立绘」 |

图片通过 `bridge.getImageUrl(relPath)` 拿带 `?t=mtime` 的 `file://` URL，
`img.onload` 成功后才移除 `hidden`、隐藏占位层——避免加载中露出破图。

## 4. 卡片质感（v1.3）

纯 CSS 实现，没有图片素材、没有第三方库：

| 手法 | 实现 | 效果 |
| --- | --- | --- |
| 分层投影 | `box-shadow: var(--shadow-card)`（主题内定义） | 卡片像浮在面板上 |
| 斜向高光 | `.char-card::after` 的 `linear-gradient(155deg, var(--sheen), transparent 34%)` | 玻璃反光质感 |
| 兜底压暗 | 同一个 `::after` 第二条渐变 `to top, rgba(0,0,0,.10)` | 亮色立绘不至于刺眼 |
| 圆角 | `--card-radius: 12px`（紧凑态 9px） | 比列表更柔和的观感 |
| 叠加顺序 | `isolation: isolate` + `::after z-index:2` + 标签/文字 `z-index:3` | 高光不遮文字 |
| 渐变文字底 | `.char-card-info` 的自下而上黑色渐变 | 任意底图上文字都可读 |

### 4.1 悬停 / 聚焦反馈

```css
.char-card:hover,
.char-card:focus-visible {
  transform: scale(1.055) translateY(-2px);
  z-index: 6;                          /* 盖住相邻卡片 */
  border-color: var(--accent);
  box-shadow: 0 18px 34px var(--shadow-color), 0 0 0 1px var(--accent-soft);
}
.char-card:hover .char-card-img { transform: scale(1.07); }   /* 封面二级放大 */
```

- **两级放大**：卡片整体 1.055，封面图再 1.07，形成「图在框里往外推」的视差；
- **过渡曲线**：`cubic-bezier(.2,.7,.3,1)` 0.22s，起手快收尾缓，手感更「弹」；
- **防裁切**：容器 `padding: 12px`，给放大留余量，边缘卡片不会被滚动容器切掉；
- **键盘可达**：`:focus-visible` 与 `:hover` 同样式，另加 `0 0 0 2px var(--accent)` 焦点环；
- **紧凑模式降级**：`scale(1.05)` 无位移，3 列密集时不至于互相压得太厉害。

### 4.2 选中态

```css
.char-card.active { box-shadow: inset 0 0 0 2px var(--accent), 0 0 0 3px var(--accent-soft); }
```

用 `inset` 描边而非改变尺寸，避免选中时卡片轻微跳动，与列表模式左侧色条形成区分。

## 5. 交互与持久化

| 行为 | 实现 |
| --- | --- |
| 点击进入详情 | `el.addEventListener('click', () => selectCharacter(Number(el.dataset.id)))` |
| 键盘进入 | `keydown` 监听 `Enter` / `' '`，`preventDefault()` 后同样调 `selectCharacter` |
| 布局记忆 | `localStorage['clw:charLayout']`，`loadLayout()` 校验必须在 `LAYOUTS` 内，否则回退 `list` |
| 切换布局 | 设置面板 → `setLayout(mode)` → `saveLayout` → `renderList()` → `syncSettingsUI()` |
| 启动恢复 | `DOMContentLoaded` 时 `state.layout = loadLayout()` |

`loadLayout()` 用 try/catch 包住 `localStorage`：隐私模式或被禁用时静默回退默认值，不抛错。

## 6. 历史修复：列表无法滚动

`#charsView` / `#storiesView` 早期没有撑满高度，角色超过一屏时内容被 `.sidebar` 的
`overflow: hidden` 裁掉且**无法滚动**。修复：

```css
#charsView, #storiesView { display: flex; flex-direction: column; flex: 1; min-height: 0; }
```

`min-height: 0` 是 flex 子项能内部滚动的必要条件（否则子项最小高度为内容高度，`overflow-y:auto` 失效）。

| v1.4 | 选中指示条由 `border-left-color` 改为 `::before`（`scaleY + opacity`，160ms），`border-left` 仅占位防跳；`renderList()` 引入指纹 `charListFingerprint()` + `syncCharActive()`，切选中项不再重建列表；新增 `imageUrl()` 图片 URL 缓存；网格/紧凑布局点击卡片时封面 → 立绘框 FLIP |
