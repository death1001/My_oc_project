# 03-02 · 搜索与筛选

## 1. 适用范围

| 层 | 位置 |
| --- | --- |
| 结构 | `index.html` 工具栏：`#searchInput`、`#filterAffiliation`、`#filterRace`、`#filterTag` |
| 逻辑 | `renderer.js` → `getTags()` / `filteredCharacters()` / `rebuildFilterOptions()` / `fillSelect()`；事件在 `bindEvents()` |
| 状态 | `state.filters = { q: '', affiliation: '', race: '', tag: '' }` |

**作用范围**：仅角色列表。独立故事库（故事视图）不参与筛选，始终展示全部。

---

## 2. 数据流

```
用户输入
  ├── 搜索框 input → debounce 180ms → state.filters.q → renderList()
  └── 下拉 change → state.filters.[affiliation|race|tag] → renderList()

角色数据变化（新建/编辑/导入/删除）
  └── loadCharacters() → rebuildFilterOptions() → renderList()
```

筛选是**纯前端内存过滤**：`state.characters` 已全量加载，`filteredCharacters()` 每次遍历一遍。
角色量级在几百以内，无需索引或后端查询。

---

## 3. 匹配规则

```js
function filteredCharacters() {
  const f = state.filters;
  const q = f.q.trim().toLowerCase();
  return state.characters.filter(c => {
    if (q && !(String(c.name || '').toLowerCase().includes(q) ||
               String(c.alias || '').toLowerCase().includes(q))) return false;
    if (f.affiliation && (c.affiliation || '') !== f.affiliation) return false;
    if (f.race && (c.race || '') !== f.race) return false;
    if (f.tag && !getTags(c).includes(f.tag)) return false;
    return true;
  });
}
```

| 维度 | 匹配方式 | 说明 |
| --- | --- | --- |
| 搜索 `q` | 姓名 **或** 别名的子串包含，大小写不敏感 | `trim()` 后为空视为不筛选 |
| 阵营 | **全等** | 下拉值来自现有数据，不会出现拼写差异 |
| 种族 | **全等** | 同上 |
| 标签 | 数组 `includes` | 一个角色有多个标签，命中任一即通过 |

四个条件之间是 **AND**，可任意组合。

> 搜索用 `includes` 而非 `startsWith`：中文姓名常被记成「姓氏在后」或只记得名号片段，
> 子串匹配更宽容。代价是无法按相关度排序——结果顺序仍是 `updated_at DESC`。

## 4. 标签的两种存储形态

`metadata.tags` 历史上存过两种格式，`getTags()` 做兼容：

```js
function getTags(c) {
  const t = c && c.metadata ? c.metadata.tags : null;
  if (Array.isArray(t)) return t.map(String);
  if (typeof t === 'string') return t.split(/[,，]/).map(s => s.trim()).filter(Boolean);
  return [];
}
```

- 数组：`["主角","剑士"]`
- 字符串：`"主角,剑士"` 或 `"主角，剑士"`（中英文逗号都认）

**新数据统一存数组**（表单里是逗号分隔输入，保存时 split 成数组），字符串分支只为兼容老数据与手工编辑过的 JSON。

## 5. 下拉选项动态生成

```js
const affs  = [...new Set(state.characters.map(c => (c.affiliation || '').trim()).filter(Boolean))]
              .sort((a, b) => a.localeCompare(b, 'zh'));
const races = /* 同上 */
const tags  = [...new Set(state.characters.flatMap(getTags))]
              .sort((a, b) => a.localeCompare(b, 'zh'));
```

- `Set` 去重，`filter(Boolean)` 去掉空字符串（未填阵营的角色不产生空选项）；
- `localeCompare(…, 'zh')` 按拼音排序，比默认 Unicode 序更符合中文阅读习惯；
- `fillSelect(sel, values, allLabel)` 重建 `<option>`，第一项固定为「全部 X」。

### 失效值重置

```js
const keep = state.filters[key] && values.includes(state.filters[key]) ? state.filters[key] : '';
state.filters[key] = keep;
```

场景：当前筛「青墨坊」，然后编辑最后一个青墨坊角色改成别的阵营 →
重新生成选项时该值已不存在，若不清空，列表会变空且下拉显示「全部阵营」但状态仍是旧值，造成「明明选了全部却没数据」。
这行代码同步清掉状态与选中项。

## 6. 交互细节

| 细节 | 实现 |
| --- | --- |
| 输入防抖 | `debounce(fn, 180)`，避免每敲一个字全量重绘 |
| 下拉即时 | `change` 事件无防抖，选择即刷新 |
| 空结果 | `#charListEmpty` 的文案是「暂无角色，点击右上角「新建角色」开始建档」——筛选为空时也显示这句（**已知不精确**，未区分「没有角色」与「没有匹配项」） |
| 计数徽标 | `#charCount` 显示**筛选后**数量，不是总数 |
| 无「清空筛选」按钮 | 需手动把三个下拉改回「全部 X」并清空搜索框 |

## 7. 修改指引

| 需求 | 做法 |
| --- | --- |
| 增加筛选维度（如按作品 `metadata.work`） | ① `index.html` 加 `<select id="filterWork">`；② `state.filters` 加 `work: ''`；③ `filteredCharacters()` 加判断；④ `rebuildFilterOptions()` 生成选项 + `fillSelect` 的 key 映射；⑤ `bindEvents()` 绑定 change |
| 搜索扩展到性格/职业/故事正文 | 在 `filteredCharacters()` 的 `q` 判断里追加字段；正文搜索需先 `bridge.listStories` 取数据或改建 FTS5 |
| 区分「空库」与「无匹配」 | 在 `renderList()` 里判断 `state.characters.length === 0` 切换两套文案 |
| 加「清空筛选」按钮 | 重置 `state.filters` 四个字段 → 重置三个 `<select>.value = ''` 与 `#searchInput.value = ''` → `renderList()` |
| 防抖时长 | `bindEvents()` 里 `debounce(..., 180)` 的第二个参数 |

## 9. 验证方式

开发者工具 Console：

```js
// 1. 搜索
document.querySelector('#searchInput').value = '雁';
document.querySelector('#searchInput').dispatchEvent(new Event('input'));
// 等待 200ms 后
document.querySelectorAll('.char-item, .char-card').length   // 应为匹配数

// 2. 筛选
const sel = document.querySelector('#filterAffiliation');
sel.value = '青墨坊';
sel.dispatchEvent(new Event('change'));
document.querySelector('#charCount').textContent             // 应为该阵营角色数

// 3. 组合后置空
sel.value = ''; sel.dispatchEvent(new Event('change'));
```

也可直接核对 `filteredCharacters()` 的返回长度与列表 DOM 节点数是否一致。
